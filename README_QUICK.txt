Browser with tabs based on QTWebEngine (like Falkon)

Browser with all:
no tab limits.

Browser with tabs:
target: computers with just 2 GB RAM
Better combined RAM usage than seperate windows/processes.
Maximum of 10 tabs supported.
Opens "target=" in same tab to save memory

Browser without tabs:
allows creation of *.desktop files of websites
Options for window like borderless and hidden navigation. So you can integrate websites like normal windows to your desktop.


Browser with JSON IPC control.
An additional remote-control using Vala/GTK, you could extend it if you need GTK integration for some reason.
Supports sending shell commands to the browser.
Maximum flexibility, for advanced projects.
